# KWin scripts

Custom KWin JavaScript scripts (`KPackage` type `KWin/Script`), one directory
per script. Each is self-contained and installable independently; see its own
README for what it does and how to install it.

## Scripts

### [`kde-osd-bottom-center/`](kde-osd-bottom-center/)

Moves Plasma's on-screen display overlay to bottom-center, just above the
panel, instead of KWin's default placement.
