# KWin customizations

KDE Plasma/KWin customizations maintained for this host. Unlike the other
directories in this collection, these are not source patches against KWin
itself — they're user-level KWin scripts, installed through KPackage rather
than applied to an upstream checkout.

## Contents

### [`kwinscripts/`](kwinscripts/)

Custom KWin JavaScript scripts. Currently one: `kde-osd-bottom-center`, which
repositions the on-screen display overlay to bottom-center.
